**Prism** — это красивая панель в стиле [ModernZ](https://github.com/Samillion/ModernZ) с удобными фишками
[uosc](https://github.com/tomasklaen/uosc) и встроенным **редактором**: двигай кнопки, меняй их размер,
цвет и действия, добавляй свои — без блокнота и без кода. Держи несколько скинов и переключай их в меню.

## 🚀 Установка за 3 шага

1. **Скачай** архив: [Download ZIP](https://github.com/VasiliskBRO/mpv-prism/archive/refs/heads/master.zip) и распакуй.
2. **Положи содержимое** в папку настроек mpv:
   - Windows — `portable_config` рядом с `mpv.exe` или `%APPDATA%\mpv\`;
   - Linux / macOS — `~/.config/mpv/`.
3. **Убери другие оболочки** (uosc, ModernZ и т.п.) из папки `scripts`, иначе будет две панели сразу.

Нужен **mpv 0.40+** (проверено на 0.41). По желанию: **Python** — для SponsorBlock,
**[streamlink](https://streamlink.github.io/)** — для эфиров Twitch/Kick,
**[yt-dlp](https://github.com/yt-dlp/yt-dlp)** — для видео по ссылке.

## 🎮 Быстрый старт

| Хочу | Что сделать |
|---|---|
| открыть меню | правый клик по видео: сверху плитки «Файл · Ссылка · Недавние · Скриншот», ниже — только то, что есть у этого видео, редкое — в «Ещё» (поиск находит и его: просто начни печатать) |
| своё меню (пункты, плитки, папки, круг) | `Ctrl+Shift+E` или «Ещё» → «Настроить меню…» — см. «Конструктор меню» ниже |
| передвинуть кнопку, поменять цвет | `Ctrl+E` → тащи мышкой, правый клик — свойства → «Сохранить» |
| добавить свою кнопку | `Ctrl+E` → правый клик по пустому месту → «Создать здесь» (или кнопка «Создать объект») |
| передвинуть громкость или кнопки окна | `Ctrl+E` → тащи их, как любые другие элементы |
| выбрать цвет | `Ctrl+E` → правый клик по элементу → «Цвет» → круг или сетка → «Готово» |
| кнопка, которая появляется сама по себе | `Ctrl+E` → «Создать объект» → «Зона наведения», у кнопки «Появляется в зоне» |
| другой дизайн панели | меню → «Скины»: «Стандарт», «Капсула», «Кино», «Неон Prism», «Островки», «Мини», «Мобильный», «VHS», «Боковая панель», «Терминал» |
| другой вариант панели | меню → «Скины» → «Новый скин» (копия) или «Пустой скин» (с нуля) |
| сменить качество стрима | `Alt+Q` |
| вернуть всё как было | `Ctrl+E` → «Как по умолчанию» → «Сохранить» |

## 🧩 Редактор оболочки

<p align="center"><img src="docs/editor.jpg" alt="Редактор" width="800"></p>

- **Тащи** элемент — переезжает, **за уголок** — меняется размер, ручка «тёмная подложка» —
  высота тёмной подложки.
- **Клавиши:** стрелки — сдвиг на 1 px (Shift — на 10), `Tab` — следующий элемент, `Delete` — убрать,
  `Ctrl+Z` — шаг назад, `Ctrl+S` — сохранить. «Выйти» с несохранёнными изменениями переспросит.
- **Правый клик — свойства:** действия левой/правой кнопки и колеса (пауза, перемотка, следующее
  видео, скриншот, громкость, скорость, меню, качество… или своя команда mpv), размер, цвет,
  **цвет при наведении** («Авто» — свой цвет кнопки не перекрашивается, «Цвет темы», «Не менять»
  или любой), прозрачность, что прятать первым в узком окне, подсказка, растянуть, по центру, удалить.
- **«Оформление»:** цвет (тема), подложка — затемнение снизу, капсула (скруглённая плашка) или без неё,
  толщина и свечение полосы перемотки, **цвет кружка** на полосе и его обводка (кружок громкости
  берёт тот же цвет). У кнопок в свойствах — «Фон кнопки» (круг) и его прозрачность,
  у текста и надписей — «Шрифт».
- **Выбор цвета** — своё окошко: переключатель «Круг / Сетка», цветовой круг с полоской яркости
  (клик или перетаскивание), серые, последние 12 цветов, «Ввести код…» (`#33FF66`). Выбранный цвет
  сразу виден на элементе; «Готово» / `Enter` — оставить, «Отмена» / `Esc` — вернуть как было.
- **«Создать объект»** или правый клик по пустому месту → **«Создать здесь»** (объект встанет
  под курсор): готовые кнопки (скриншот, громче/тише, скорость 1.5×, ±30 с, главы, поверх
  окон, качество стрима, открыть файл…), своя кнопка с иконкой из списка, надпись, встроенные элементы,
  **плашка** (скруглённая подложка под группу кнопок), **зона наведения**.
- **Кнопки окна** (свернуть / развернуть / закрыть) и **регулятор громкости** — тоже элементы:
  их можно двигать и растягивать (у громкости ширина — толщина, высота — длина; её зона наведения
  переезжает вместе с ней). Удалённую кнопку окна вернёт «Встроенный элемент».
- **Шкала громкости** — правый клик по регулятору (или «Оформление» → «Шкала громкости»):
  максимум шкалы (100 / 130 / 150 / 200 %), шаг колёсика и стрелок, показывать ли цифру,
  цвет заливки и положение — **вертикально или горизонтально** (лёжа: динамик слева, цифра справа).
  Всё сохраняется в скин.
- **Панель редактора** прячется, пока тащишь элемент; кнопка «⇅» переносит её в середину экрана,
  чтобы не мешала ставить кнопки наверху.
- **«Как по умолчанию»** возвращает скин к его исходному виду (копии лежат в `skins/defaults/`),
  а скин, сделанный через «Новый скин», — к тому, с которого его скопировали.
- **Зоны наведения** — цветные прямоугольники: где мышь вызывает нижнюю панель, верхнюю (кнопки окна)
  и громкость. Их можно двигать, растягивать и удалять (удалённая зона больше не срабатывает,
  вернуть — «Создать объект» → «Вернуть стандартную зону»). Свою зону создай в «Создать объект»,
  потом у кнопки в свойствах выбери «Появляется в зоне» — кнопка будет появляться сама по себе,
  когда мышь в этой зоне, без остальной панели (плавно, и прячется, как только мышь ушла).
- Положение считается от левого края, центра или правого края окна — это выбирается само,
  поэтому панель правильно растягивается при любом размере окна.

### 🧩 Конструктор меню

Меню по правому клику собирается из блоков, как хочешь. Открыть: правый клик → «Ещё» →
**«Настроить меню…»** или `Ctrl+Shift+E`. Всё сохраняется сразу в `menus/*.json`, `Ctrl+Z` — шаг назад.

- **Блоки:** готовый пункт (их ~40: открыть файл/ссылку, субтитры, скорость, громкость, пауза, ±10 с,
  главы, полный экран, PiP, поверх окон, скины, выход…), **своя кнопка с любой командой mpv**,
  **ряд плиток** (крупные или в строку), **папка** (своё подменю, вложенность любая), заголовок раздела, линия.
- **У пункта:** название, иконка, подсказка справа, цвет, «приглушённый» и **когда показывать** —
  когда есть смысл (главы — если есть главы), всегда, только при видео, только без видео.
- **Двигать:** клик по блоку → «Выше / Ниже / Переместить в…», или `Alt+↑` `Alt+↓`; `Del` — убрать.
- **Оформление:** форма — **список или круг** вокруг курсора (у папки — своя), где появляется
  (по центру / у курсора / панелью сбоку), ширина, высота строк, размер текста, скругление,
  плотность фона, затемнение экрана, цвет выделения, заголовок.
- **Круг:** наведи и кликни, или зажми правую кнопку, веди в сторону и отпусти. Больше 8 кнопок —
  остальные в «Остальное». Начни печатать — круг станет списком с поиском.
- **Несколько меню:** «Мои меню» — какое открывается по правому клику, какое по `Tab`, копии,
  переименование, новые из шаблонов (Пульт, Простой список, Круг, Пустое). «Посмотреть» — проверить как есть.
- Последний пункт «Настроить меню…» в меню правого клика удалить нельзя, чтобы не потерять дорогу назад.
- Пока открыт конструктор, видео на паузе. Одновременно открыт только один редактор: `Ctrl+E` из
  конструктора переключает на редактор оболочки, `Ctrl+Shift+E` — обратно (если в редакторе оболочки
  есть несохранённые правки, он попросит сначала сохранить или выйти).

### 🖼 Свои иконки

Кидай файлы в папку **`icons\`** профиля (имена — латиницей) — они появятся в выборе иконки
(раздел «Мои иконки») и в конструкторе меню, и у своих кнопок в редакторе оболочки. Там же есть
«Открыть папку с иконками» и «Обновить список».

- **SVG** — как родные иконки: чёткие, перекрашиваются в цвет пункта и темы, плавно гаснут с панелью.
  Нужны иконки с заливкой (контурные части с `fill="none"` пропускаются). Брать: fonts.google.com/icons,
  iconify.design, svgrepo.com → Download SVG.
- **PNG** (и JPG, WebP) — цветная картинка как есть (эмоут, логотип). Не перекрашивается и на панели
  появляется без плавного затухания. mpv один раз сам переводит её в нужный размер (кэш в `~~cache/prism-icons`).

<details>
<summary><b>⚙️ Настройки</b></summary>

Всё в `script-opts/hybrid.conf` (с комментариями): тема, шаг скорости и громкости, где громкость,
вид значка паузы, размер «картинки в картинке» и т.д. Полный список — в начале
`scripts/hybrid/main.lua` (таблица `user_opts`).

- `theme=prism` — фирменная тема; есть ещё `orange`, `blue`, `purple`, `green`, `red`, `pink`.
- `layout=skin` — панель из скина (`skins/*.json`), `skin=standard` — скин по умолчанию.
- `layout=default` — классическая раскладка без редактора: кнопки включаются строками
  `menu_button`, `shuffle_button`…, ширина линейки — `speed_ruler_width`.
- `click_pause=yes` — пауза по одиночному клику (в этом конфиге выключена).
- `volumebar_match_seek_color=no` — белая заливка громкости вместо цвета темы.
- `jump_mode=exact` — перемотка ±10 с ровно на 10 секунд (по умолчанию — к ближайшему ключевому кадру, быстрее).

Внутри скрипт называется `hybrid` (папка `scripts/hybrid`, привязки `script-binding hybrid/...`) —
так сложилось исторически, на работу это не влияет.
</details>

## ❓ Частые вопросы

**Две панели сразу / панель не появляется.** В папке `scripts` осталась другая оболочка (uosc,
ModernZ, osc.lua) — убери её. На Windows mpv читает настройки и из папки рядом с `mpv.exe` — проверь обе.

**Не меняется качество стрима.** Для эфиров Twitch/Kick нужен установленный streamlink, для роликов —
yt-dlp. Пункт «Качество» появляется только у стримов и видео по ссылке.

**Сломал панель в редакторе.** `Ctrl+E` → «Как по умолчанию» → «Сохранить». Или меню → «Скины» →
«Стандарт».

**Иконки показываются квадратиками.** Не скопировалась папка `fonts` — положи её рядом со `scripts`.
